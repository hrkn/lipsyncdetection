# 🎥🎵 Media & Lip Sync Detector (Rust)

動画・音声ファイルを開き、トラック間の同期ポイント（ズレ時間）を自動検出し、ミリ秒単位での手動調整およびミックス再生比較をサポートするRust製GUIアプリケーションです。

---

## ✨ 主な機能

- **マルチメディア & 多トラック解析**: 2つ以上の動画/音声ファイルを同時読み込みし、任意のビデオトラック・音声トラックを選択可能
- **先頭5秒 自動同期検出**:
  - **ビデオトラック**: フラッシュ・明滅・急速な画面変化のピーク ($T_{\text{video}}$ ms) を検出
  - **音声トラック**: クラップ音や破裂音（アタック感）の音量急変・エネルギーオンセットのピーク ($T_{\text{audio}}$ ms) を検出
  - **遅れ時間（ミリ秒）自動提示**: トラック間の同期に必要なミリ秒オフセット（$\Delta t$ ms）と検出信頼度を表示
- **インタラクティブ変化量グラフ**: `egui_plot` による 0.0s ～ 5.0s の時系列変化波形および同期ピーク位置のガイド線描画
- **手動微調整 & マウスホイール対応**:
  - **通常ホイール回転**: `±10 ms` 微調整
  - **Shift + ホイール回転**: `±100 ms` 高速調整
  - **Ctrl + ホイール回転**: `±1 ms` 超精密微調整
  - 精密ボタン (`-100ms`, `-10ms`, `-1ms`, `+1ms`, `+10ms`, `+100ms`) およびスライダー調整
- **リアルタイム ミックス再生比較**: オフセットを適用した状態で複数トラックの音声を同時再生し、音量・ミュート調整で同期状態を確認可能
- **日本語GUI対応**: Windowsシステムフォント自動適用による高精細な日本語UI

## 📦 対応コンテナ形式およびコーデック一覧

FFmpegバックエンドを使用しているため、主要な動画・音声コンテナおよび標準コーデックに広範に対応しています。

| コンテナ形式 | 拡張子 | 主な特徴・用途 | 格納可能な主な動画コーデック | 格納可能な主な音声コーデック |
| :--- | :--- | :--- | :--- | :--- |
| **MP4** | `.mp4`, `.m4v` | 標準的な汎用動画形式 | H.264 / AVC, H.265 / HEVC, AV1, VP9, MPEG-4 | AAC, MP3, Opus, ALAC, AC-3 |
| **Matroska** | `.mkv` | 高機能オープンコンテナ | H.264, H.265, AV1, VP8, VP9, ProRes, MPEG-2 | AAC, MP3, FLAC, Opus, Vorbis, PCM, AC-3, DTS |
| **QuickTime** | `.mov` | Apple標準動画フォーマット | ProRes, H.264, H.265, Motion JPEG, MPEG-4 | AAC, Linear PCM, ALAC, MP3 |
| **AVI** | `.avi` | 従来の汎用動画形式 | Motion JPEG, MPEG-4, Xvid, DivX, Raw Video | PCM (WAV), MP3, AC-3 |
| **WebM** | `.webm` | Web向けオープン動画 | VP8, VP9, AV1 | Opus, Vorbis |
| **WAV** | `.wav` | 無圧縮・高音質音声 | *(音声専用)* | PCM (16bit / 24bit / 32bit), Float |
| **MP3** | `.mp3` | 標準的圧縮音声 | *(音声専用)* | MP3 (MPEG-1 Layer III) |
| **M4A / AAC** | `.m4a`, `.aac` | 高音質圧縮音声 | *(音声専用)* | AAC-LC, HE-AAC |
| **FLAC** | `.flac` | 可逆圧縮音声 | *(音声専用)* | FLAC |

## 🛠 動作要件・前提条件・必要ランタイム

- **OS**: Windows 10 / 11 (64-bit)
- **Rust**: 1.97.0 以上（ソースコードからビルドする場合）
- **FFmpeg / FFprobe**:
  - `ffmpeg` および `ffprobe` がシステム環境変数 `PATH` に通っていること（または `lipsyncdetection.exe` と同一ディレクトリに配置されていること）
- **Microsoft Visual C++ 再配布可能パッケージ (MSVCランタイム)**:
  - 構築した `.exe` ファイルの実行には `vcruntime140.dll` 等を提供する **Visual C++ 2015–2022 再配布可能パッケージ (x64)** が必要です（多くの環境にはインストール済みですが、エラーで起動しない場合は [Microsoft 公式ページ](https://learn.microsoft.com/ja-jp/cpp/windows/latest-supported-vc-redist?view=msvc-170) よりダウンロードして導入してください）。
- **OS標準機能 (追加導入不要)**:
  - **グラフィック**: Direct3D 11/12 または OpenGL（GUI描画用）
  - **オーディオ**: WASAPI（音声再生用）
  - **フォント**: Windows標準日本語フォント（メイリオ / BIZ UDゴシック / 遊ゴシック / MSゴシック）

## 🚀 ビルド & 実行方法

### 1. リポジトリのビルド
```powershell
cargo build --release
```

### 2. アプリケーションの起動
```powershell
cargo run
```

### 3. テストの実行
```powershell
cargo test
```

## 💡 使い方

1. アプリを起動し、「**📂 メディアファイルを開く**」ボタンから比較したい動画/音声ファイルを2個以上開きます。
2. 左パネルから **基準トラック (Track 1)** と **対象トラック (Track 2)** を選択します。
3. 「**⚡ 先頭5秒 自動同期検出**」をクリックします。
4. 中央パネルに描画された波形グラフと推奨オフセット時間を確認します。
5. 下部パネルの「**▶ ミックス再生**」ボタンを押して音声を聴きながら、マウスホイール（`Shift` / `Ctrl` 併用可）やボタンでズレを微調整します。
